## ▶️ Ejecutar localmente

Clona el repositorio:

```bash
git clone https://github.com/JoseArmando9715/Portafolio.git
```

Entra al proyecto:

```bash
cd Portafolio
```

Instala las dependencias:

```bash
npm install
```

Ejecuta el servidor de desarrollo:

```bash
npm run dev
```
